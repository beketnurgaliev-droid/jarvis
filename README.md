# Джарвис

Голосовой помощник для Windows: висит в трее, слушает микрофон офлайн,
просыпается на слово **«Джарвис»**, выполняет команду и отвечает голосом.

Распознавание речи — [Vosk](https://alphacephei.com/vosk/), целиком на вашем
компьютере, в интернет ничего не уходит. Отвечает мужским системным голосом
`Microsoft Pavel` и обращается к вам «сэр». Всё, что не разобрано локально,
уходит к подключённым ИИ — каким угодно: бесплатный ключ, платный ключ или
подписка (см. «ИИ» ниже).

## Установка

Нужна Windows 10/11 и микрофон. Распакуйте папку **в путь без русских букв**
(например, `C:\Jarvis` — иначе распознавание не загрузит модель) и запустите
**Установить.bat** (или `powershell -ExecutionPolicy Bypass -File install.ps1`).

Установщик скачает модель распознавания (маленькую — 46 МБ или большую —
1,8 ГБ, слышит заметно лучше; на ПК с памятью меньше 12 ГБ советует маленькую),
спросит ключ Gemini, при желании поставит Claude Code, добавит ярлык в меню
«Пуск» и запуск при входе в Windows. Права администратора не нужны.

Python в систему ставить не нужно, если в архиве есть папка `runtime` (так в
архиве для друга): там свой Python Джарвиса с библиотеками, ~190 МБ. Без неё
установщик поставит Python и соберёт окружение `venv`, как раньше.

## Память и процессор

Почти всю память и процессор занимает модель распознавания, а не сам Джарвис
(Python со всеми библиотеками — ~95 МБ). Большая модель — ~1,6 ГБ памяти,
маленькая — ~0,6 ГБ. В режиме «Автоматически» (панель → «Голос и слух» →
«Производительность», `"model_path": ""`) на ПК с памятью меньше 12 ГБ Джарвис
берёт маленькую, при необходимости скачивает её и переходит на ходу.

«Не слушать тишину» (`performance.skip_silence`, по умолчанию включено): пока
звук не громче фона, распознавание не запускается; фон — самый тихий звук за
последние 8 с, так что и шум вентилятора через несколько секунд считается
тишиной. Проверка — `tests\test_gate.py` (синтезированные фразы в шуме: фразы
не теряются, процессора уходит вдвое меньше). Раз в 10 минут в журнале —
сколько процентов времени распознавание работало.

«Место на диске» в той же вкладке — удалить ненужную модель, отключённые части
большой модели (`_rnnlm.off`, `_rescore.off` — ~2,3 ГБ) и `venv`, когда Джарвис
работает на своём Python.

Ключ Gemini бесплатный: [aistudio.google.com/apikey](https://aistudio.google.com/apikey)
→ «Create API key». Подписка Gemini для этого не нужна.

## ИИ

Панель → «ИИ» → «+ Подключить ИИ» → выбрать, что есть:

| Что есть | Как подключается |
|---|---|
| Бесплатный ключ: Gemini, Groq, OpenRouter | вставить ключ |
| Платный ключ: OpenAI (ChatGPT API), DeepSeek, Claude API | вставить ключ |
| Подписка Claude Pro/Max, ChatGPT Plus, Google AI Pro | «Установить» → «Войти в аккаунт» (Claude Code, Codex CLI, Gemini CLI) |
| Своя модель (Ollama, LM Studio) или любой OpenAI-совместимый адрес | адрес, ключ, модель |

Джарвис спрашивает их по очереди сверху вниз; порядок — стрелками. ИИ без
поиска в интернете вопросы про погоду и новости отдаёт следующему, кто умеет
искать. Ключи хранятся в `keys.dat`, зашифрованном Windows: на другом
компьютере или под другим пользователем их не прочитать. Подписка и ключ API —
разные вещи: ChatGPT Plus или Claude Pro по ключу не подключить, только через
программу.

Запуск вручную: `wscript start-jarvis.vbs`

## Панель

Щелчок по значку в трее (или «Джарвис, открой панель») открывает окно настроек:
состояние, ключ Gemini и проверка связи, Claude, голос с прослушиванием,
микрофон и имена для обращения, программы, выученные ослышки, журнал и сборка
архива для друга. Панель работает только на этом компьютере: адрес `127.0.0.1`,
случайный порт и пароль-токен на каждый запуск Джарвиса.

## Поделиться с другом

Панель → «Поделиться» → «Собрать архив» (или `venv\Scripts\python.exe package.py`).
На рабочем столе появится `Джарвис-ДАТА.zip` — только программа, панель,
расширение и установщик. Ключ, настройки, журнал и ослышки в архив не попадают.
Друг распаковывает в `C:\Jarvis`, запускает **Установить.bat** и вставляет свой ключ.

## Обновления

Новые версии выпускаются релизами в закрытый репозиторий на GitHub (`updater.REPO`):

    venv\Scripts\python.exe package.py --release

— код уходит в репозиторий, архив — релизом `vX.Y`. Номер берётся из `version.py`,
второй раз тот же не выпустить. Джарвис с ключом доступа (`keys.dat` → `github`)
проверяет релизы через пару минут после запуска и каждые 6 часов, скачивает
архив в `updates\`, ждёт тихого момента и запускает `update.py`: тот сохраняет
прежние файлы в `backup\`, ставит новые (личное не трогает), при новом
`requirements.txt` доставляет библиотеки и запускает Джарвиса. Не отозвался
за 3 минуты — возвращает прежнюю версию. Журнал — `logs\update.log`.

### Свой Python (runtime)

    venv\Scripts\python.exe package.py --runtime

— собирает `runtime\<runtime.WANTED>` (встроенный Python с python.org той же
версии, что в venv, + библиотеки из venv; pip не кладёт) и выпускает его
отдельным релизом `runtime-<имя>` (не «последним»). Какой Python запускать,
написано в `runtime\current.txt`; его читают `start-jarvis.vbs` и `run.vbs`
(через `run.vbs` идут ярлыки панели и раскладки окон), нет файла — venv.

Джарвис из venv сам скачивает нужный runtime, проверяет импортом всех
библиотек и модулей и в тихий момент запускает `update.py --runtime ИМЯ`:
тот переключает `current.txt`, запускает Джарвиса и ждёт отзыва в
`updates\runtime.json`; не отозвался — возвращает прежний Python. После
перехода ярлыки, запускавшие `venv\…\pythonw.exe`, переводятся на `run.vbs`.

Поменялись библиотеки — новое имя `runtime.WANTED`, `package.py --runtime`,
потом `--release`: Джарвис на своём Python сначала скачает новый runtime, потом
поставит код и переключит Python одним `update.py`.

Первая установка у друга — архив с ключом внутри: `package.py --friend`
(ключ на чтение репозитория лежит у автора в `keys.dat` → `friend_github`).
Без ключа обновления выключены — так у автора ничего само не меняется.
Голосом: «проверь обновления», «обновись»; в панели — карточка на Главной.

## Как пользоваться

Скажите «Джарвис», дождитесь короткого писка — значок в трее позеленеет — и
командуйте. Можно одной фразой: «Джарвис, запусти хром». После команды он
ещё 20 секунд слушает без обращения по имени, чтобы не повторять его каждый
раз. «Отбой» — вернуться в ожидание.

| Что сказать | Что будет |
|---|---|
| «запусти хром», «открой ворд» | ищет программу в меню «Пуск» |
| «включи на ютубе цой группа крови» | находит первый результат и включает |
| «громкость тридцать», «тише», «громче» | системная громкость |
| «пауза» | медиа-клавиша, работает в любом плеере |
| «громкость ютуба на двадцать», «на ютубе потише», «музыку громче» | громкость в самом плеере ютуба через расширение Chrome (см. ниже); без расширения — громкость Chrome в микшере Windows. Общая громкость не меняется |
| «следующая песня», «переключи песню», «давай другую», «предыдущая» | листает ютуб в браузере (через медиасеансы Windows) и называет новую песню; браузер ничего не играет — медиа-клавиша |
| «открой в браузере телеграм», «открой сайт ютуб», «зайди на озон» | открывает сайт в браузере по умолчанию (список имён — в `browser.py`, дописывайте свои) |
| «загугли рецепт борща», «найди в браузере погоду» | поиск в браузере по умолчанию |
| «открой вкладку», «открой вкладку телеграм» | новая вкладка — пустая или сразу с сайтом |
| «который час», «какое сегодня число» | скажет вслух |
| «скриншот» | снимок экрана в «Изображения\Jarvis» |
| «что за песня играет», «кто поёт» | название и исполнитель — в любом плеере (ютуб, Спотифай, Яндекс Музыка) |
| «как там комп», «что грузит комп», «сколько места на диске», «сколько свободной памяти» | процессор, память, диски, температура видеокарты NVIDIA, батарея ноутбука — без ИИ |
| «что на экране», «что за ошибка», «посмотри на экран и скажи …» | снимок **активного окна** уходит подключённому ИИ (нужен тот, что видит картинки: Gemini, ChatGPT по ключу, Claude) |
| «переведи выделенное (на английский)», «прочитай выделенное», «объясни это», «перескажи выделенное», «переведи из буфера» | копирует выделенный текст и возвращает прежний буфер обмена; ничего не выделено — смотрит на экран. Длинный ответ — начало вслух, целиком в буфер обмена |
| «напиши привет как дела» | печатает в активное окно: «Привет, как дела?» — знаки расставляет ИИ (без ИИ — как услышал). «С новой строки» — Shift+Enter, чтобы чат не отправил сообщение |
| «заблокируй», «выключи компьютер» | **переспросит** — нужно ответить «да» |
| всё остальное | уходит агенту Claude Code |

Программы ищутся по звучанию, а не по точному названию: «ворд» находит
Microsoft Word, «энидеск» — AnyDesk, «нвидиа» — NVIDIA App. Меню «Пуск» на
латинице, поэтому сравнение идёт по транслитерации и согласному остову слова.
Пары, которые звучат совсем иначе («блокнот» → notepad, «эксель» → excel),
прописаны в `config.json` в разделе `apps` — туда же добавляйте свои.

Значок в трее: серый — ждёт обращения, зелёный — слушает команду,
синий — выполняет, красный — на паузе. Правая кнопка: пауза, перечитать
список программ, открыть лог, выход.

## Агент работает только на чтение

По умолчанию `"allow_actions": false`. Агент отвечает на вопросы, смотрит
файлы и ищет в сети, но **не выполняет команд в системе и не правит файлы**.

Это сделано намеренно. Малая модель Vosk ошибается на похожих словах, а
голосом отдаются поручения, которые могут дойти до рабочих серверов.
Ослышка не должна превращаться в выполненное действие.

Чтобы разрешить действия, в `config.json`:

```json
"claude": { "allow_actions": true }
```

Тогда перед каждым поручением агенту Джарвис переспросит вслух и будет ждать
«да». Включайте, только убедившись, что распознавание на вашем микрофоне
работает чисто.

## Настройка

Всё в `config.json` (создаётся из `config.example.json` при установке):

| Ключ | Зачем |
|---|---|
| `wake_words` | варианты того, как слышится «Джарвис». Ложно срабатывает — уберите лишние; не слышит — добавьте из лога |
| `wake_similarity` | порог похожести слова-будильника, 0.78 по умолчанию |
| `command_timeout` | сколько секунд слушать без обращения по имени |
| `match_threshold` | порог подбора программ, 0.70 |
| `apps` | пары «как говорю» → «что запускать» |
| `mic_device` | номер микрофона, если их несколько; `null` — системный по умолчанию |
| `voice.name` | голос: `Pavel` — мужской, `Irina` — женский |
| `voice.engine` | `auto` — где найдётся, `onecore` — системный, `sapi` — старый |
| `voice.rate` | скорость речи, от −10 до 10 |
| `voice.pitch` | высота тона, 1.0 — как есть, меньше — ниже |
| `claude.cwd` | рабочая папка агента; пусто — домашняя |

Пути к модели и к `claude.exe` можно не указывать — находятся сами.

## На слабом ПК

Распознавание речи (Vosk) работает постоянно и заметно грузит процессор —
на слабой машине из-за этого могут проседать игры и программы. Панель →
«Голос и слух» → «Производительность»:

| Настройка | Что делает |
|---|---|
| Модель распознавания | **маленькая** грузит процессор в разы меньше (выбор для слабого ПК, слышит чуть хуже), **большая** — точнее. Смена применится после перезапуска |
| Не мешать играм и программам | пониженный приоритет процесса — Windows отдаёт процессор игре первым. Включено по умолчанию, на отзывчивость команд почти не влияет |
| Пауза в полноэкранной игре | в игре на весь экран Джарвис перестаёт распознавать и почти не грузит процессор; голос вернётся, когда свернёте игру. По умолчанию выключено |

Раздел `performance` в `config.json`: `low_priority` и `pause_in_fullscreen`.

## Если что-то не так

**Не реагирует на имя.** Откройте лог (`logs\jarvis.log`) — там всё, что он
услышал. Найдите, во что превратилось «Джарвис», и добавьте этот вариант в
`wake_words`.

**Срабатывает сам по себе.** Уберите из `wake_words` короткие варианты и
поднимите `wake_similarity` до 0.85.

**Молчит.** Проверьте, что в системе есть русский голос: «Параметры → Время и
язык → Речь». Без русского голосового пакета говорить будет нечем. `Pavel`
живёт только в системном движке (OneCore) — в списке голосов «Панели
управления» его нет, и это нормально: Джарвис берёт его напрямую. Если его
нет и там, поставьте в настройках `"name": "Irina"`.

**Слышит сам себя.** На время своей речи микрофон глушится, но при громких
колонках эхо всё равно доходит — уменьшите громкость или наденьте наушники.

**Правите `install.ps1`.** Сохраняйте в UTF-8 **с BOM**, иначе PowerShell 5.1
покажет кириллицу кракозябрами. А `start-jarvis.vbs` — наоборот, в **UTF-16
LE**: Windows Script Host не принимает UTF-8 BOM и отказывается запускаться
с ошибкой «недопустимый знак».

## Расширение Chrome «Джарвис для ютуба»

Громкость внутри плеера ютуба снаружи Windows не достать, поэтому в папке
`chrome-extension` лежит маленькое расширение. Оно подключается к Джарвису
(`ws://127.0.0.1:8765`, только с этого компьютера) и выполняет его команды
прямо в плеере.

Установка один раз: `chrome://extensions` → включить «Режим разработчика»
(справа сверху) → «Загрузить распакованное расширение» → выбрать папку
`chrome-extension`. Папку после этого не переносить. Подключилось ли — видно
в логе: «Расширение ютуба подключилось».
